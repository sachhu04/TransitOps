# Contributing to TransitOps

First off, thank you for considering contributing to TransitOps! It's people like you that make TransitOps such a great tool.

### 1. Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check if there's already an issue open for it. If not, open a new issue!

### 2. Fork & create a branch

If this is something you think you can fix, then fork TransitOps and create a branch with a descriptive name.

### 3. Get the test suite running

Make sure you're using Node.js version 20 and have a PostgreSQL database available.

```bash
npm install
npm run test
```

### 4. Implement your fix or feature

At this point, you're ready to make your changes. Feel free to ask for help!

### 5. Create a Pull Request

Once your tests are passing, open a pull request!
